SHOTLYTICS V5.1 — CAMERA HOTFIX

This hotfix corrects a JavaScript syntax error in V5 that prevented the page script from running reliably in Safari. It retains the combined single-screen camera layout.

Install:
1. Extract this ZIP.
2. Upload and replace index.html, manifest.webmanifest and sw.js in the ROOT of your existing GitHub repository.
3. Commit the changes and wait for GitHub Pages to deploy.
4. On the iPad, reload the existing GitHub Pages URL. If needed, open it with ?v=51 at the end.

Do not delete the repository or clear Safari website data. The existing shot history key remains shotlytics-shots-v1.

For best no-scroll layout, use iPad landscape orientation. Camera access requires HTTPS and permission.
